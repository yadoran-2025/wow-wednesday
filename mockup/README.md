# 놀라운 수요일 목업

실행: 프로젝트 루트에서 `node webapp.mjs` → http://127.0.0.1:4173/mockup/index.html

## 파악한 현재 기능

| 영역 | 현재 동작 | 확인한 제약 |
| --- | --- | --- |
| 문제 제작 | 제목·음원 파일 또는 링크·재생 구간·받쓰판 문장 입력, 실시간 정답 미리보기 | 입력 영역이 긴 한 열에 몰려 있음 |
| 문제 보관 | 저장·수정 저장·새 문제로 저장·불러오기·삭제 | 기본 자료와 내 문제의 선택 UI가 분리됨. 내 문제는 선택 후 불러오기를 한 번 더 눌러야 함 |
| 미디어 | YouTube, 직접 링크, 업로드 음원; 구간 슬라이더·시간 직접 입력 | 수업 진행에서 타이머가 매초 전체 DOM을 재생성하므로 미디어가 다시 생성됨 |
| 수업 규칙 | 규칙 화면 표시·텍스트 수정·기본값 복원 | 수업 규칙과 실제 기본 타이머 시간이 다름(3분 / 90초) |
| 수업 진행 | 받쓰판·글자 클릭 힌트·0.5초 힌트·정답 공개·타이머 | 진행 중 문제 이동 UI가 없음. 화면의 문제 수는 1 / 1로 고정 |
| 데이터 | 텍스트는 localStorage, 음원은 IndexedDB | 계정 동기화·내보내기 기능 없음. data/problems.json은 빈 배열 |
| 외부 연결 | 다른 수업 참고 3개, 대시보드 링크 | 참고 메뉴는 hover/focus 방식 |

근거: `src/app.js`의 renderMaker, renderSavedProblemLibrary, renderRunner, renderProblemMedia, syncTimer 및 `data/problems.json`. 띄어쓰기 힌트는 상태/처리 코드가 있지만 현재 화면에 연결된 조작 버튼은 없으므로 활성 기능으로 세지 않았다.

## 설계

교사가 한 수업의 문제를 준비하고, 학생들에게 문제를 제시하며 진행하는 도구로 구성했다.

- 준비: 문제 목록 → 편집 → 학생 화면 미리보기. 문제를 누르면 바로 편집하고, 별도 불러오기/사용 버튼을 없앰.
- 진행: 받쓰판을 중심으로 배치. 문제 이동·음원 구간·타이머·힌트를 같은 화면에서 조작.
- 규칙: 규칙을 수정하고 바로 학생용 화면으로 전환. 규칙에 나오는 의논 시간과 기본 타이머를 3분으로 통일.
- 정답 공개는 확인 후 실행. 전체 공개와 플래시 힌트는 별도 동작으로 유지.
- 작은 선택지는 버튼으로 노출. 문제 수가 많아지면 검색으로 좁힘.
- 원본 문제 자료 사이트 3개(현수토리·초읍중 주연지·무극중 최주영)는 모든 화면 상단에 항상 표시하고, 원본 URL을 그대로 새 탭에서 연다. 외부 대시보드는 준비 화면 상단에 둠.
- 브랜드 옆에 `by 현수토리 선생님`을 표시한다. 모든 화면 상단의 `출처` 버튼은 사용자가 지정한 `https://m.blog.naver.com/PostList.naver?blogId=kimhsu1`을 새 탭에서 연다. 모바일에서는 이름 아래에 저자를 배치해 출처 버튼과 겹치지 않게 한다.

색: 작업 배경 #f4f6fb, 종이 #ffffff, 본문 #202b46, 주요 행동 #4855ce, 무대 #1b2b4b, 힌트 #d9ed9a.
서체: Apple SD Gothic Neo/Pretendard 계열의 굵은 제목과 본문, SFMono 계열의 시간/숫자.
핵심 시각 요소: 방송의 정답판을 연상시키는 번호가 붙은 글자 타일. 주변 UI는 조용하게 유지한다.

## 클릭해서 확인할 흐름

1. 문제 선택 → 제목/문장/구간 수정 → 미리보기의 받쓰판/정답 전환 → 문제 저장.
2. 새 문제 → 입력 → 문제 저장. 복제·삭제·목록 검색도 동작한다.
3. 수업 시작 → 글자 타일 클릭 → 힌트 되돌리기 → 초성/랜덤 글자/단어 하나 공개 → 0.3초 힌트 → 정답 공개/다시 가리기.
4. 타이머 시간 선택·시작·일시정지·초기화. 문제 앞뒤 이동. 전체 화면.
5. 수업 규칙 수정 → 규칙 보여주기 → 문제 시작.

## 목업 범위

기존 앱과 저장소를 읽거나 바꾸지 않는다. 예시 문장은 목업용으로 직접 작성했다. 예시 음원은 무음 재생 시뮬레이션이다. 파일을 선택하면 해당 파일의 실제 구간 재생을 시험할 수 있다. 링크는 검증 후 새 탭에서 여는 방식이며 YouTube 임베드/구간 재생 연동은 하지 않았다.

저장·수정·삭제는 이 페이지를 연 동안만 유지된다. 새로고침하면 예시로 돌아간다. 서버/브라우저 영구 저장, 수업 세트 관리, 점수판, 학생별 제출 기능은 추가하지 않았다. 기존 앱의 타이머/미디어 문제는 이 목업에서 화면 전체를 다시 그리지 않는 방식으로 피했으며, 원본 코드를 수정하지 않았다.

## 검증

- `node mockup/self-check.mjs`: 시간 형식 검증, HTML 이스케이프, 줄바꿈 뒤 글자 위치, 준비 화면의 힌트 분리, 정답 공개 검사 통과.
- Chrome 자동 조작: 검색·편집·저장·복제·삭제·구간 입력 오류·글자 힌트/되돌리기·0.3초 힌트·정답 확인·규칙 수정·문제 이동 통과.
- 타이머와 재생을 동시에 실행해 시간이 흐르는 동안 받쓰판 DOM이 유지되는지 확인.
- 테스트 WAV 파일 업로드 후 1–3초 구간을 재생하고, 힌트 조작 중 재생 유지와 구간 끝 정지를 확인.
- 1440/1024/768/650/390/320px에서 세 화면의 가로 넘침 없음. 데스크톱과 모바일 스크린샷 육안 검토.
- YouTube 임베드·실제 외부 링크 재생·브라우저별 전체 화면 동작은 검증하지 않음.

## 힌트 수정

- 수업 진행 받쓰판의 타일과 숫자를 확대했다. 817px 화면 기준 타일 40×50 → 56×72px.
- 순간 정답 보기는 0.3초로 변경했다.
- 초성 보기는 한글 음절의 초성만 표시하고 다시 가릴 수 있다. 영문·숫자를 정답으로 노출하지 않는다.
- 랜덤 한 글자는 아직 열리지 않은 글자 하나를 공개한다.
- 단어 하나 공개는 공백으로 나눈 어절 중 미공개 글자가 남은 어절 하나를 공개한다.
- 힌트 되돌리기는 마지막 글자/단어 공개 또는 초성 전환을 한 번에 되돌린다. 기존에 열어 둔 글자는 보존한다. 문제 이동·문장 편집 시 힌트를 초기화한다.
